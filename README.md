# Download Time Calculator

A small iOS app that tells you how long a download will take. Type a file size and a connection speed; the estimate updates as you type.

- Sizes in KB / MB / GB / TB (1000 or 1024 based)
- Speeds in Kbps / Mbps / Gbps / MB/s
- One-tap presets for common files and connections
- "Done around" clock time, real-world speed slider, and a comparison at other speeds
- Remembers your last inputs

Open `Download Time Calculator.xcodeproj` in Xcode and run. See [PLAN.md](PLAN.md) for the roadmap and [LOG.md](LOG.md) for the change history.
